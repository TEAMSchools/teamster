    Branching Minds SFTP Ingestion Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Load the 13 Branching Minds nightly CSV exports from the BrM SFTP /exports folder into GCS/BigQuery and build stg_branchingminds__* staging models in kipptaf.

    Architecture: 13 build_sftp_file_asset assets in a new kipptaf branchingminds module, partitioned by fiscal year, fed by one new sensor that keys partitions on file mtime. dbt reads the Avro partitions through external sources; 1 staging model per file renames, casts, drops BrM demographics, and dedupes across yearly partitions.

    Tech Stack: Dagster, paramiko SFTP (SSHResource), Pydantic + py_avro_schema, dbt on BigQuery.

    Spec: docs/superpowers/specs/2026-10-22-branchingminds-sftp-ingest-design.md

    All paths are relative to the worktree /workspaces/teamster/.claude/worktrees/cbini/feat/claude-branchingminds-sftp-ingest. Run every command with that as cwd, uv run always, and git -C <worktree>.

    Global Constraints

    • Code location kipptaf; SSH resource key ssh_branchingminds (already wired). No changes to dagster-cloud.yaml.
    • Watch only /exports. Never match anything under /incoming_files/.
    • Partitions: FiscalYearPartitionsDefinition(start_date="2026-07-01", timezone=str(LOCAL_TIMEZONE), start_month=7).
    • Partition key = fiscal-year start of the file's mtime in America/New_York.
    • Sensor cursor = per-asset max matched mtime, never wall-clock time.
    • An asset run for a partition other than the current fiscal year raises.
    • Avro fields are all str | None; staging casts.
    • Staging drops BrM demographics: student name parts, state ID, grade level, gender, race/ethnicity, English proficiency, gifted, mandated learning plan, ELL status.
    • The local student ID becomes student_number in every staging model.
    • Staging keeps district, school_id where present, and _dagster_partition_fiscal_year as source_fiscal_year.
    • Every staging model: config.meta.contains_pii: true at model level; every test sets config: severity explicitly.
    • No PII values in commits, PR text, or issue comments. Recon output stays in the session scratchpad.

    Review Focus

    • A file written between 00:00 and 00:59 ET on July 1 must land in the new fiscal year, and one at 23:59 ET on June 30 in the old one (Task 3 test).
    • A drop whose mtime is older than an asset's cursor but newer than another asset's cursor must trigger only the asset it belongs to (Task 3 test).
    • A manual launch of a past fiscal-year partition must fail, not overwrite that year's frozen snapshot (Task 4 test).
    • A 0-byte file must not trigger a run that writes an empty partition over a good one (Task 3 test).
    • A drop whose newest school_year disagrees with its partition must surface as a warning in dbt (Task 6 test).

    Task 3: Library sensor

    Files:

    • Create: src/teamster/libraries/branchingminds/sensors.py
    • Create: src/teamster/libraries/branchingminds/CLAUDE.md
    • Test: tests/libraries/test_branchingminds_sensor.py

    Interfaces:

    • Produces: build_branchingminds_sftp_sensor(code_location: str, timezone: ZoneInfo, asset_selection: list[AssetsDefinition], remote_dir: str, minimum_interval_seconds: int | None = None) -> SensorDefinition. Sensor name f"{code_location}__branchingminds__sftp_sensor"; one job f"{code_location}__branchingminds__sftp_asset_job" over all assets; the sensor function takes ssh_branchingminds: SSHResource. Cursor is a JSON object {asset python identifier: max mtime float}.

    Behavior: one ssh_branchingminds.listdir_attr_r_or_skip(remote_dir=remote_dir) per tick; return the SkipReason if one comes back. For each asset, match re.match(remote_file_regex, f.filename); take files with st_size > 0 and st_mtime > cursor[asset]. Partition key = FiscalYear(datetime.fromtimestamp(mtime, tz=timezone), start_month=7).start.isoformat(). Skip with a warning a key not in the asset's partitions def. Set cursor[asset] to the max matched mtime. Group by partition key into one RunRequest(run_key=f"{job_name}_{partition_key}_{max_mtime}", partition_key=..., asset_selection=[keys]).

    • Step 1: Write the failing tests, with a MagicMock SSH returning (SFTPAttributes, path) pairs as in tests/libraries/test_edplan_sensor_partition_timezone.py, and 2 throwaway build_sftp_file_asset assets (a.csv, b.csv) on the spec partitions def:
    • test_june_30_late_evening_is_prior_fiscal_year: mtime 2027-06-30 23:59 EDT → ["2026-07-01"].
    • test_july_1_early_morning_is_new_fiscal_year: mtime 2027-07-01 00:30 EDT → ["2027-07-01"].
    • test_cursor_is_per_asset_max_mtime: with t = 2026-10-01 12:00 EDT as epoch seconds, cursor {a: t + 200, b: t + 100}, files a.csv and b.csv at mtime t + 150 → one request selecting only b; returned cursor {a: t + 200, b: t + 150}. (Mtimes must fall inside the partitions def, or the out-of-range skip hides the cursor behavior.)
    • test_empty_file_is_skipped: st_size = 0 → no run requests, cursor unchanged.
    • test_changed_assets_share_one_run: both files new, same fiscal year → exactly 1 RunRequest whose asset_selection holds both keys.
    • test_skip_reason_passes_through: listdir_attr_r_or_skip returns a SkipReason → the sensor returns it.
    • Step 2: Run; expect ImportError. uv run pytest tests/libraries/test_branchingminds_sensor.py -q
    • Step 3: Implement build_branchingminds_sftp_sensor per the behavior above.
    • Step 4: Run; expect 6 passed.
    • Step 5: Write CLAUDE.md: one sensor for all BrM exports; the partition comes from mtime because BrM rolls its window July 1 and 6 files have no school-year column; cursor is per-asset max mtime.
    • Step 6: Commit feat(branchingminds): add SFTP sensor.
