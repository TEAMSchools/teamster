    ARFR Status Labels Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: DeansList report cards print the dashboard's ARFR labels, and promotion-in-doubt letters match the 2026-27 draft, live before the Friday 11/13/2026 print.

    Architecture: One dbt extract view (rpt_deanslist__promo_status) changes the values DeansList receives. Three DeansList Report Manager sources change through the scratch splice workflow: scripts read a pulled live copy, apply asserted edits, and write paste targets that the user pastes and saves.

    Tech Stack: dbt (BigQuery), dbt unit tests, Python splice scripts, Handlebars/JS DeansList reports, Claude in Chrome for read-only pulls.

    Spec: docs/superpowers/specs/2026-11-11-arfr-status-labels-design.md

    Global Constraints

    • Everything is live and render-tested by Thursday 11/12 evening; print is Friday 11/13 in every region.
    • Label strings, exactly: At-Risk for Retention, On-Track (Academic Warning), On-Track (Attendance Warning), On-Track, Off-Track.
    • Camden letter sentence, exactly: Failing 3 or more core classes means automatic retention with no summer school eligibility.
    • K-2 letter note, exactly: NOTE: K-2 data reflects DIBELS, and 3-4 data reflects iReady
    • This repo is public. DeansList source, vendor docs, and student data stay under .claude/scratch/deanslist/ (gitignored). Nothing from there is committed or pasted into GitHub.
    • The agent never saves in Report Manager. The user pastes and saves; the agent produces paste targets, a paste list, and checksums.
    • Pull live and compare before every edit. Save a checksummed baseline before any paste; the baseline is the rollback.
    • Always uv run for Python and dbt. Worktree: /workspaces/teamster/.claude/worktrees/anthonygwalters/fix/claude-arfr-status-labels.
    • DeansList source GUIDs: letter E0E7E752-2ED1-DAF6-8C2C-5E8950CF55F0 (owner KIPP BOLD Academy); MS/HS report card 4D5EFD16-E225-B041-D4D0-B1B86404FA5D (owner KIPP Cooper Norcross HS); ES report card DD312901-BD2A-D9FA-63DA-5134AB473955 (owner KIPP Lanning Square Primary).

    Review Focus

    • A student with no PROMOSTAT row for the term must print -, never undefined or a blank page. Owned by Tasks 4 and 5 (gate plus render check).
    • Camden detection that silently fails falls back to 90%; a Camden grade 5-8 letter must print 88%. Owned by Task 4 (render check).
    • The Spanish warning labels are longer than the English ones, and the ES report card's Overall cell does not wrap. Owned by Task 7 (render check).
    • A missing translation prints English; confirm on one Spanish letter and one Spanish report card before Friday. Owned by Task 7.
    • Each source is shared by every school that installs it, so a paste changes all of them at once, including schools that are not printing. Owned by Task 6 (paste list names this).
