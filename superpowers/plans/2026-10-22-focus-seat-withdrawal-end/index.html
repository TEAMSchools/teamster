    End Focus seats on the withdrawal date — Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Miami (Focus) course seats end no later than the student's withdrawal, and seats that start after it disappear, matching NJ.

    Architecture: The Focus package model int_focus__schedule gains effective_end_date and drops seats that start after the student's enrollment end at that school and year. kipptaf's int_students__course_enrollments builds exit_date from the new column. One PR, using the existing zz_stg_ branch on kippmiami_focus.

    Tech Stack: dbt (BigQuery), dbt unit tests, BigQuery MCP for verification.

    Spec: docs/superpowers/specs/2026-10-22-focus-seat-withdrawal-end-design.md

    Global Constraints

    • end_date on int_focus__schedule stays the raw Focus value.
    • New column is in Focus's last-day-enrolled convention. kipptaf adds 1 day for exit_date, as it already does for cc_dateleft.
    • is_dropped_section and cc_dateleft in kipptaf keep reading raw end_date.
    • The enrollment end for a student, school and syear is null when any of that student's enrollments there that year is open, else the latest end_date.
    • A seat is removed only when its start_date is after that enrollment end. A seat starting on the end date is kept.
    • A seat with no enrollment row at its school and year is kept unchanged.
    • None of the other kipptaf consumers of int_focus__schedule (int_focus__advisory, int_students__final_grades, int_students__course_sections, int_students__teacher_grade_levels, rpt_littlesis__enrollments, bridge_course_section_teachers) reads seat end_date; they change only by losing removed rows. No edits there.
    • Before any local dbt build, invoke the dbt-local-dev skill for target, --defer and --state flags. --target staging builds are shared writes: ask the user first, and run them in their own Bash call.

    Review Focus

    1. A student still enrolled (open enrollment) keeps every seat to its term end. Pinned in Task 1 (student 21).
    2. A student who withdrew and came back to the same school, still enrolled, is not clamped at the first exit. Pinned in Task 1 (student 22).
    3. A seat that starts on the withdrawal day is kept and ends that day. Pinned in Task 1 (seat 14).
    4. A real mid-term drop keeps its own earlier end date, and kipptaf still flags it dropped. Pinned in Task 1 (seat 12) and checked in Task 2 step 4.
    5. A student whose only open seats all start after the withdrawal loses them, which leaves no open seat, so kipptaf's withdrawal-sweep rule reads their real drops as not dropped. Measured in Task 2 step 4; report the count, do not fix in this PR.

    • Step 3: Implement in int_focus__schedule.sql

    • Final select: deduplicated left-joined to enrollment_end on student_id, schoolid = school_id, academic_year = syear. Project every existing column, then (select min(d) from unnest([end_date, marking_period_end_date, enrollment_end_date]) as d) as effective_end_date.
    • where e.enrollment_end_date is null or s.start_date <= e.enrollment_end_date.
