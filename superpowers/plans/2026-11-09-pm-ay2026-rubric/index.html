    PM reporting for the AY2026 Grow rubric Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: AY2026 coach scores flow through PM outlier detection and the teacher development dashboard the way Grow scores them.

    Architecture: The script's dbt input gains 7 core-value columns and a measure_set column. The fit logic moves into a pure library helper that fits each measure set separately. Teacher development selects ETR measures by name prefix and adds a Values average that fills the 20% slot.

    Tech Stack: dbt on BigQuery, Dagster, pandas, scikit-learn, pytest.

    Spec: docs/superpowers/specs/2026-11-09-pm-ay2026-rubric-design.md

    Global Constraints

    • Worktree: /workspaces/teamster/.claude/worktrees/kevinverhoff/fix/claude-pm-ay2026-rubric. Run every command from it, with git -C <worktree> and absolute paths. Never cd to the main checkout.
    • Always uv run for dbt, dagster, python, pytest.
    • Invoke the dbt-local-dev skill before the first local dbt build.
    • Open dbt files with the Read tool so .claude/rules/dbt-*.md load.
    • No warehouse DML/DDL and no Dagster partition launches; the backfill is Kevin's, in the Dagster UI.
    • Verification queries go through the BigQuery MCP (execute_sql_readonly), aggregates only. Never paste staff names or employee numbers into commits or GitHub.
    • ETR measures: measurement_name like 'ETR-%' (named ETR-1A: … through ETR-5C: … in every year from AY2023).
    • Core-value shortnames, after the existing shortname expression: EXCELLENCE, FUN, KID FOCUS, PRESENCE, PUNCTUALITY, RADICAL LOVE, TEAM. Columns: excellence, fun, kid_focus, presence, punctuality, radical_love, team.
    • Grow strands: Values (Excellence, Fun, Kid Focus, Radical Love, TEAM), Professionalism and Punctuality (Presence, Punctuality).
    • measure_set values: etr_so, etr_values.
    • AY2023 is the cutover for the ETR-only filter in teacher development; AY2018–22 keep not like '%S&O%'. Comment the literal (S20).
    • Before pushing SQL, YAML, or markdown: /workspaces/teamster/.trunk/tools/trunk check --force --no-fix <files> </dev/null.
    • Stage named files only; never git add -A.

    Shipping in 2 PRs

    The staging outlier model reads the script's Avro files through an external table. Old files lack the new columns until every partition is re-run, so staging cannot select them in the same PR without failing CI.

    • PR 1 (this branch, Tasks 1–5): #6250's fix, the extract, the script, the Avro schema, teacher development. The new columns land in the Avro files but staging ignores them.
    • After merge and deploy, Kevin re-runs every outlier partition in the Dagster UI.
    • PR 2 (Task 6, a follow-up issue filed in Task 5): carry the new columns through stg_performance_management__outlier_detection and rpt_tableau__pm_outlier_detection.
