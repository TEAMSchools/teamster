    Suspension Google Sheet Feed Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Add rpt_gsheets__suspensions, one row per DeansList suspension consequence for the current and prior academic year, and its Google Sheets exposure.

    Architecture: A kipptaf rpt_ view reads int_deanslist__incidents__penalties, int_deanslist__incidents__attachments, and int_extracts__student_enrollments, the same models rpt_tableau__okrts_referrals reads. Each suspension takes school and student fields from the enrollment stint that covers its created date, falling back to the year's rn_year = 1 stint. The 2 DeansList reads are layer rule A1 edges, recorded in standard-baseline.tsv under #5811.

    Tech Stack: dbt (BigQuery), dbt unit tests, trunk.

    Spec: docs/superpowers/specs/2026-11-03-suspension-gsheet-feed-design.md

    Global Constraints

    • Worktree: /workspaces/teamster/.claude/worktrees/anthonygwalters/feat/claude-suspension-gsheet-feed (<wt> below). Use git -C <wt> and absolute paths on every call.
    • Window: create_ts_academic_year >= {{ var("current_academic_year") - 1 }}.
    • Rows: is_suspension only. No referral-tier filter.
    • Output academic_year is the display string (2025-26), from academic_year_display. The window filter compares the integer year.
    • No context, is_chronically_absent, or is_tier3_4 column.
    • No Miami remap. Miami rows appear only once #5790 remaps upstream.
    • Every join between 2 unioned models includes _dbt_source_project (A10).
    • No row_number() ... = 1 pick, qualify, or dbt_utils.deduplicate in the model (A5). Pick stints with join predicates and rn_year.
    • SQL style: .claude/rules/dbt-sql.md (S1-S20). YAML: .claude/rules/dbt-yaml.md.
    • dbt runs from the main checkout: uv run dbt <cmd> --project-dir <wt>/src/dbt/kipptaf --target dev, adding --defer --favor-state --state /workspaces/teamster/src/dbt/kipptaf/target/prod for builds and tests.

    Review Focus

    1. An incident created on a transfer day, where one stint exits and the next enters, takes the entering stint's school. Unit test row 9002.
    2. An incident created outside every stint of its year (summer, after a withdrawal) keeps its row and takes the rn_year = 1 stint. Unit test row 9003.
    3. An incident_id that repeats in 2 regions never pulls the other region's letters. Unit test fixture kippcamden attachment on incident 501.
    4. A suspension whose student matches no enrollment (today, every Miami row) drops out rather than appearing with blank student fields. Unit test row 9006.
    5. A suspension older than the window drops out, so the July rollover moves the window. Unit test row 9005.

    • Step 3: Write rpt_gsheets__suspensions.sql

    CTEs, in order:

    • suspensions: penalties columns from the table above plus _dbt_source_project, student_school_id, create_ts_academic_year, and date(create_ts_date) as created_date; where is_suspension and the window filter.
    • enrollment_picks: one row per suspension, carrying incident_penalty_id, _dbt_source_project, and the picked stint's entrydate:
    coalesce(ed.entrydate, ey.entrydate) as entrydate
-- ed: left join enrollments on student, academic year, project,
--     ed.entrydate <= s.created_date and ed.exitdate > s.created_date
-- ey: left join enrollments on student, academic year, project,
--     ey.rn_year = 1
    • attachments: per attachment, incident_id, _dbt_source_project, file_posted_at__date, entity_name, public_filename, format_datetime('%F', file_posted_at__date) as posted_date, is_suspension_letter (attachment_type = 'INC-LETTER' and entity_name in the 7 names rpt_tableau__okrts_referrals lists in its attachments CTE), and is_upload (attachment_type = 'UPLOAD').
    • attachment_labels: suspension_letter_label is concat(entity_name, ' (', posted_date, ')') when is_suspension_letter, else null; upload_label is the same from public_filename when is_upload.
    • attachment_rollup: grouped by incident_id, _dbt_source_project; string_agg(<label>, '; ' order by file_posted_at__date) for suspension_letters and other_uploads. string_agg skips the null labels.

    Final select: suspensions inner join enrollment_picks on incident_penalty_id and _dbt_source_project, inner join int_extracts__student_enrollments on student, academic year, project, and entrydate, left join attachment_rollup on incident_id and _dbt_source_project. Columns in the table's order, enumerated (A9).
