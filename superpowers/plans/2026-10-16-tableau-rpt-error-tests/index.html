    Tableau rpt Error Tests (PR 5 of #5948) Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Every test on a rpt_tableau__* model runs at error, except grain tests that fail in prod on a tracked source defect, which stay warn with a TODO(#N).

    Architecture: Add a kipptaf: extracts: tableau: +severity: error block. Move the 11 business-unit accepted_values tests from the rpt_ models to the 2 upstream models that first see those values, and delete the student_tier enum test, which the upstream bucket model already guards. Pin warn on the int_tableau__* tests the folder block would otherwise flip, and on the 6 failing grain tests. Set severity explicitly on the singular tests in tests/. No model SQL changes.

    Tech Stack: dbt (BigQuery), kipptaf project.

    Spec: docs/superpowers/specs/2026-10-15-mart-test-rule.md and the sorting rule in .claude/rules/dbt-yaml.md → Test config defaults. Precedent: docs/superpowers/plans/2026-10-16-dim-error-tests.md (#5983).

    Global Constraints

    • Worktree: /workspaces/teamster/.claude/worktrees/cbini/test/claude-tableau-rpt-error-tests, branch cbini/test/claude-tableau-rpt-error-tests. Use git -C <worktree> and absolute paths. Always uv run. Stage with git add -u (plus explicit new paths).
    • dbt commands run from src/dbt/kipptaf in the worktree. Prod-deferred form: uv run dbt <cmd> --target dev --defer --favor-state --state /workspaces/teamster/src/dbt/kipptaf/target/prod. Select with path:models/extracts/tableau. That selection also picks up the singular tests in tests/ that read a Tableau model.
    • Scope: tests already on extracts/tableau/ models, plus the 2 upstream accepted_values tests Task 2 adds. Adding grain tests to the 48 rpt_ models with none is a follow-up PR, not this one.
    • int_tableau__* tests keep their current severity. The rule covers marts and rpt_ only.
    • A warn test carries # TODO(#N): <one line> on the line above, N an open issue.
    • PR body: Refs #5948 (no Closes). No PII in commits, comments, or the PR; counts and column names only.
    • Lint before push: /workspaces/teamster/.trunk/tools/trunk check --force --no-fix <files> </dev/null from inside the worktree.

    college_assessment_dashboard_de: in 196 of the 198 groups, one PowerSchool stored grade joins more than one row of stg_powerschool__u_storedgrades_de (different DE course and semester). Which row wins is the dashboard owner's call. No issue tracks it yet; Task 1 records it on #5889.

    Test sorting:

    • Moved upstream (source data, earliest model that sees it):
    • 10 home_business_unit_name accepted_values → 1 test on int_people__staff_roster.home_business_unit_name, warn. The rpt_ entity logic already maps any business unit it does not know to Region, so a new ADP business unit has a downstream defense.
    • rpt_tableau__operations_ekg.school_business_unit_name accepted_values → 1 test on stg_google_sheets__people__locations.location_region, error (staging tests are always error).
    • Deleted as an upstream promise: rpt_tableau__academic_goals_dashboard.student_tier accepted_values. int_students__bucket_assignments already gates Buckets 1-3 at error, and Bucket 4 is the coalesce default.
    • Kept and flipped to error: every not_null, every passing grain test, the 3 DIBELS singulars and the GPA singular. All pass in prod.
    • Removed severity: warn overrides on passing tests: 1 in rpt_tableau__manager_survey_details.yml, 2 in rpt_tableau__operations_ekg.yml.
    • Kept warn (int, out of scope): the int_tableau__state_assessments_demographic_comps accepted_values and grain tests, the 3-column int_tableau__fresh_enrollment_scaffold grain test, and test_int_tableau__fresh_goals_scaffold_region_matches_scaffold.

    Review Focus

    • A warn override removed from a test that fails in prod turns CI red. Every removal must match a test that passed in the Task 1 run.
    • The 2 new upstream tests run on far more rows than the rpt_ copies did. Each must return 0 in prod before it lands at its planned severity.
    • The folder block also reaches the int_tableau__* tests. dbt ls must show all 4 int warn tests still at warn.
    • A column whose last test is deleted must not keep an empty data_tests: key, and tested columns stay at the top of columns:.
    • The TODO(#N) issues must all be open when the PR opens.
