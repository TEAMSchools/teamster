    Newark PowerSchool 504 Flag from EdPlan Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Newark's nightly student AutoComm file gains a 21st column, S_NJ_STU_X.PID_504_TF, that mirrors active EdPlan 504 plans for currently enrolled students and writes back PowerSchool's own value for everyone else.

    Architecture: kipptaf reads Newark's EdPlan 504 report through a new source and union_relations pass-through. A rollup keeps one row per student with an active plan. The shared kipptaf rpt_powerschool__autocomm_students view computes the column for Newark rows, null for other regions. Only Newark's wrapper selects it, last.

    Tech Stack: dbt (BigQuery), kipptaf and kippnewark projects; Dagster extracts unchanged.

    Spec: docs/superpowers/specs/2026-11-16-newark-autocomm-504-design.md (approved 2026-11-16, issue #6423).

    Global Constraints

    • Worktree: /workspaces/teamster/.claude/worktrees/anthonygwalters/feat/claude-newark-autocomm-504 (call it <wt>). Use git -C <wt> and absolute paths. Always uv run.
    • Newark only. The region test is the literal 'kippnewark' on _dbt_source_project, with a one-line comment (S20).
    • New column: s_nj_stu_x__pid_504_tf, int64, contains_pii: true. It is the last column of the Newark wrapper. Camden and Paterson wrappers do not change.
    • Active plan: event_selector = 'Currently Valid: Section 504 Plan' and (end_date is null or end_date >= current_date('{{ var("local_timezone") }}')).
    • Write-back rule, first match wins: region not Newark → null; Newark has no active plans tonight → current value; enroll_status != 0 → current value; active plan → 1; else 0. Current value is if(stg_powerschool__s_nj_stu_x.is_504, 1, 0), so a missing row gives 0. Never coalesce the EdPlan flag with the PowerSchool value.
    • A Newark row never carries a blank in the new column; a blank clears the field in PowerSchool.
    • The pass-through, the rollup, and the AutoComm model stay views, so "today" is evaluated when the 03:05 extract reads them.
    • PII: student-level rows stay in the terminal and the session scratchpad. GitHub gets aggregates with no cell under 10.
    • A --target staging write needs the user's go-ahead in the turn right before it, in its own Bash call, with the consent restated.

    Review Focus

    1. A plan ending today (end_date = current_date) counts as active. Pinned by rollup fixture 1007 (Task 1).
    2. A student with 2 active plan rows still gets 1 rollup row. Pinned by rollup fixture 1006 (Task 1).
    3. A Newark student with no S_NJ_STU_X row gets 0, not null. Pinned by fixture 2005 (Task 2).
    4. An EdPlan plan for a student who is not in the file adds no row. Pinned by rollup row 9999 in the Task 2 fixture.
    5. A night with no active plans in the EdPlan report writes back every Newark value. Pinned by Task 2's second unit test.
