    Cube Validation: Validator Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: A command-line validator that compares each Cube measure with its dashboard, a source anchor, or its sibling measures, at 1 shared moment rebuilt from BigQuery, and hands the analyst a triage list.

    Architecture: A Python package scripts/cube_validation/ builds BigQuery SQL for both sides "as of" a Cube fact build (time travel, views expanded to base tables, clock functions pinned) and runs every comparison inside BigQuery, so student-level rows never leave the warehouse. Per-view configuration and the analyst's recorded decisions live in src/cube/validation/<view>.yml. Tableau is touched only to prove a workbook formula once, through a copy in TEMP-CB.

    Tech Stack: Python 3.13 (uv run), google-cloud-bigquery (ADC), tableauserverclient, pyyaml, stdlib hmac/urllib for Cube REST, pytest.

    Spec: docs/superpowers/specs/2026-10-26-cube-validation-and-build-skill-design.md (Part 1 only). Carried-over rules: docs/superpowers/specs/2026-10-26-cube-validation-approved-rules.md. Issue

    6150.

    Worktree: /workspaces/teamster/.claude/worktrees/cristinabaldor/feat/claude-cube-validation-and-build-skill (W below). Run every command with cd W && first, and git -C W for git. IDE Pyright errors on worktree files are false positives; trust uv run.

    Global Constraints

    • No production change: no extract refresh, no schedule change, no Tableau content written outside the TEMP-CB project.
    • The tool never posts to Slack. Anything posted to GitHub shows counts under 10 as <10. Row-level output never leaves local files or BigQuery; nothing committed names a person.
    • Every comparison runs inside the 7-day time-travel window of its moment.
    • The compiled SQL is the raw query, not Cube's 1 pre-aggregation.
    • The Cube token's email must have the network grant; refuse if the compiled school filter lists fewer schools than the network scope.
    • Each Cube view in scope reads 1 fact; a measure that reads 2 facts is refused.
    • Decisions live in src/cube/validation/<view>.yml, never under src/cube/model/.
    • Build fresh: do not port code from the deleted first tool (closed PR #5961).
    • Each run prices its queries with BigQuery dry runs first and states the cost; --max-usd defaults to 5.
    • Commands that need the Tableau PAT or CUBE_API_SECRET run under the pytest secrets fixture through a throwaway tests/test_zz_cube_validation.py, with --tb=short. BigQuery uses ADC and needs no fixture.
    • No new pyproject.toml dependencies. Cube's JWT is signed with stdlib hmac; HTTP uses urllib.request.
    • Never bare uv run pytest: run uv run pytest tests/scripts/cube_validation only (tests/ holds live integration tests).

    Review Focus

    1. A view in the dashboard's lineage changed its SQL after the moment: the rebuild must use the view's SQL as it stood then (from CREATE VIEW jobs), not today's. Test in Task 3.
    2. No fact build inside the time-travel window, or --moment older than 7 days: a plain refusal naming the window, not a BigQuery error. Test in Task 3.
    3. Compiled SQL that reads the pre-aggregation, reads 2 facts, or carries a short school list: refused with the reason. Test in Task 4.
    4. A Google Sheets external table in the lineage: read live and named in the result, never silent. Test in Task 2.
    5. A decision whose SQL changed only in whitespace or comments stays quiet; a logic change asks for re-confirmation. Test in Task 6.

    Task 8: Proving a workbook formula

    Files:

    • Create: scripts/cube_validation/tableau.py
    • Test: tests/scripts/cube_validation/test_tableau.py, fixture fixtures/sheet_formats.twb (a trimmed .twb with 1 worksheet and 2 measures, no data)

    • displayed_decimals(format_string: str) -> int: digits of the compared value, so a percent counts its fraction: "p0.0%" → 3, "p0%" → 2, "n#,##0" → 0, "0.00" → 2.

Read the refresh start before and after the exports; if it moved, discard the exports and retry once. Parameter cuts are out of scope for automated proof (the Tableau MCP returns 400 on parameters here); the result lists them as "prove in the browser".
