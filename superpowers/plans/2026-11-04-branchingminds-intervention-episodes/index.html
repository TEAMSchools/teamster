    Branching Minds Intervention Episodes Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: One row per student, intervention, academic year, and continuous assignment span from Branching Minds plans, with is_current, and is_sipps on the enrollments hub rewired to read it.

    Architecture: A source intermediate int_branchingminds__intervention_plans_rollup splits each plan at the July 1 fiscal boundary, then collapses overlapping or back-to-back plans per student, intervention, and year into episodes with a gaps-and-islands window pass. int_extracts__student_enrollments drops its PowerSchool course join for is_sipps and left-joins a distinct student-year projection of the rollup.

    Tech Stack: dbt (kipptaf project), BigQuery, dbt unit tests, trunk (sqlfluff, yamllint, markdownlint).

    Spec: docs/superpowers/specs/2026-11-04-branchingminds-intervention-episodes-design.md

    Global Constraints

    • Worktree: /workspaces/teamster/.claude/worktrees/anthonygwalters/feat/claude-branchingminds-intervention-episodes. Every path below is relative to it. Every uv run dbt call passes --project-dir src/dbt/kipptaf from the worktree root.
    • --state is absolute: /workspaces/teamster/src/dbt/kipptaf/target/prod.
    • Model name int_branchingminds__intervention_plans_rollup (A3 reshape suffix). Folder src/dbt/kipptaf/models/branchingminds/intermediate/.
    • Grain: student_number, intervention_name, academic_year, episode_start. academic_year is the fiscal year's start year (date_to_fiscal_year(..., start_month=7, year_source="start")), matching the enrollment models.
    • Two plans merge when the later one starts at most 1 day after the running max end of the earlier ones. A null end date is open-ended and keeps the episode open.
    • is_current uses current_date('{{ var("local_timezone") }}').
    • is_sipps counts intervention_name like 'SIPPS%' (SIPPS and SIPPS Challenge), any episode in the year.
    • No qualify (S1); no group by 1, 2 (S2); the window pass is a CTE plus a where. Tests at severity: error. config.meta.contains_pii: true on the rollup.
    • Unit-test fixtures use format: sql (the staging relation has no prod copy for dict-format introspection); expect dict scalars unquoted; every expect row lists the same columns.
    • Commit messages are conventional commits ending with the Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com> line. Never push to main.
    • Before pushing, lint changed files: /workspaces/teamster/.trunk/tools/trunk check --force --no-fix <files> </dev/null from the worktree root. Formatting findings are the commit hook's.

    Review Focus

    1. A plan whose end date is before its start date (BrM data error): the row must not crash the window pass; it yields an episode with episode_end < episode_start and is_current = false. Test in Task 1.
    2. The same plan id exported twice with identical dates (staging dedupes on plan id, so this only arrives as 2 distinct ids with the same dates): 1 episode with plans_in_episode = 2. Test in Task 1.
    3. A plan with a null end that started in a prior school year: 1 row per year from its start year through the current school year, the last one open. Test in Task 1.
    4. A SIPPS Challenge plan with no plain SIPPS plan sets is_sipps. Test in Task 2 (dev build check, since the hub has no unit test harness).
    5. Two overlapping plans at 2 different BrM schools: 1 episode, school_id from the later-starting plan. Test in Task 1.

    • Step 3: Write the model SQL

    CTEs, in order:

    1. plans: from ref("stg_branchingminds__intervention_plans"), the 8 consumed columns, plus start_academic_year and end_academic_year via date_to_fiscal_year on start and on coalesce(end, current_date(tz)); where intervention_start_date is not null.
    2. plan_years: cross join unnest(generate_array(start_academic_year, end_academic_year)) as academic_year; year_start = greatest(start, date(academic_year, 7, 1)); year_end = least(end, date(academic_year + 1, 6, 30)) when end is not null, else date(academic_year + 1, 6, 30) when academic_year < end_academic_year, else null; year_end_or_max = coalesce(year_end, cast('9999-12-31' as date)) for the window.
    3. plans_ranked: max(year_end_or_max) over (partition by student_number, intervention_name, academic_year order by year_start, year_end_or_max rows between unbounded preceding and 1 preceding) as prior_max_end.
    4. plans_flagged: if(prior_max_end is null or year_start > date_add(prior_max_end, interval 1 day), 1, 0) as is_new_episode.
    5. plans_numbered: sum(is_new_episode) over (partition by student_number, intervention_name, academic_year order by year_start, year_end_or_max rows between unbounded preceding and current row) as episode_number, plus row_number() over (same partition and episode_number order by year_start desc, intervention_plan_id desc) as rn_latest for the attribute pick.
    6. episodes: group by student_number, intervention_name, academic_year, episode_number: min(year_start) as episode_start, max(year_end_or_max) as episode_end_or_max, count(*) as plans_in_episode, array_agg(intervention_plan_id order by intervention_plan_id) as intervention_plan_ids, and max(if(rn_latest = 1, school_id, null)), same for district and intervention_subject_area.

    Final select: the grain columns, attributes, if(episode_end_or_max = '9999-12-31', null, episode_end_or_max) as episode_end, is_current as current_date(tz) >= episode_start and current_date(tz) <= episode_end_or_max, and {{ dbt_utils.generate_surrogate_key(["student_number", "intervention_name", "academic_year", "episode_start"]) }} as intervention_episode_key. Put a 1-line comment on the sentinel literal (S20) and on the 1-day adjacency literal.
