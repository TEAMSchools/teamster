    NJ 504 flag from the PowerSchool state field Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Make the NJ branch of is_504 read PowerSchool's state field PID_504_TF in every school year, and give schools a one-time worklist to correct PowerSchool records.

    Architecture: PR 1 adds a boolean is_504 to the powerschool package model stg_powerschool__s_nj_stu_x. After Dagster rebuilds it in all 3 NJ districts, PR 2 swaps suf.is_504 for njs.is_504 in kipptaf int_students__student_enrollments. The worklist is a Google Sheet built from a scratchpad script, outside the repo.

    Tech Stack: dbt (BigQuery), Dagster+, BigQuery MCP, Google Drive and Sheets MCP, Python with pandas for the worklist.

    Spec: docs/superpowers/specs/2026-11-10-nj-504-state-field-design.md (issue #6354)

    Global Constraints

    • Package derivation, verbatim: if(pid_504_tf = 1, true, false) as is_504.
    • kipptaf NJ branch, verbatim: coalesce(njr.pid_504_tf, njs.is_504, false). The Miami branch (ar.is_504) does not change.
    • Expected flagged enrollment rows after PR 2 (from the spec, measured 2026-11-10; school fixes between then and the build move these by a few):
    Region School years Today After
    Newark 2026–27 83 86
    Camden 2026–27 46 48
    Paterson 2026–27 0 11
    Newark 2021–22 to 2025–26 724 702
    Camden 2021–22 to 2025–26 268 260
    Paterson 2021–22 to 2025–26 11 11
    Newark before 2021–22 791 709
    Camden before 2021–22 154 135
    • No student-level values in the repo, a commit, a PR, an issue, or a comment. Outbound counts are region-level aggregates with no cell under 10.
    • Work in the worktree by absolute path: git -C <worktree>, uv run, and --project-dir <worktree>/src/dbt/<project>.
    • Invoke the dbt-local-dev skill before the first local dbt command, and use its dev target, --defer, and --state flags on every build below.
    • Run /workspaces/teamster/.trunk/tools/trunk check --force --no-fix <files> </dev/null from inside the worktree before each push.
    • Shared staging writes (--target staging) need the user's go-ahead in the turn just before, each in its own Bash call.
    • PR bodies follow .github/pull_request_template.md. PR 1 says Refs #6354. PR 2's branch links to #6354, and its body says Closes #6354.

    Review Focus

    1. A district rebuilds late. If PR 2 merges before all 3 district prod tables carry is_504, the kipptaf union null-fills the column and every NJ current-year flag reads false. PR 2 must not merge until Task 2's check passes. Task 4 Step 1 re-runs that check.
    2. PID_504_TF never touched. The field defaults to No, so a null reads false, never null. Task 1 Step 4 asserts 0 nulls.
    3. Past enrollment with no S_NJ_REN_X row. These rows, mostly before 2021–22, must fall back to S_NJ_STU_X, not to false. Task 4 Step 6 checks the "before 2021–22" rows: Newark 709 and Camden 135, not the lower counts that false would give.
    4. Miami. Its values, nulls included, must not move. Task 4 Step 6 compares Miami's true and null counts by year against prod.
    5. Grain. The change swaps a column from a join that already exists, so the row count must equal prod. Task 4 Step 6 checks it. The worklist keeps one row per student even when a student is in 2 groups (Task 3 Step 3).

    Task 3: Build the one-time worklist (outside the repo)

    Files:

    • Create: worklist.py in the executor's session scratchpad (never committed), with a load.py beside it that reads the EdPlan exports
    • Output: a Google Sheet named NJ 504 worklist <build date> in the user's Drive, unshared.

    Interfaces:

    • Consumes: the raw PowerSchool fields pid_504_tf and c_504_status. It does not need Task 1, so it can run as soon as the user is ready.
    • EdPlan inputs, Newark only:
    • Google Sheet "TEAM 504 - 20261110" (Sheet1 and EDPlan-504StudentReport), downloaded as .xlsx through the Drive connector.
    • EdPlan's R100 504 eligibility report for njteamcharter, dated 2026-11-10, supplied by the user as a local file.

    • At task start, ask the user whether newer exports or a Camden export exist.

    • Step 1: Pull PowerSchool current students for all 3 regions

    Use ADC from Python, as in ps_pull.py, and write to scratch CSV. The pull covers enroll_status = 0 and dcid >= 1 from each district's stg_powerschool__students, stg_powerschool__s_nj_stu_x, and stg_powerschool__schools, plus Newark and Camden stg_powerschool__u_studentsuserfields. Columns: student_number, last and first name, school, grade, pid_504_tf, c_504_status.

    • Step 2: Derive EdPlan status for Newark

    Assign each student exactly one status, in this order:

    • current plan: in Sheet1 with End Date on or after the build date.
    • plan past end date: in Sheet1, End Date before the build date.
    • lapsed: in R100, not in Sheet1.
    • not eligible: a Currently Valid: Section 504 Non-Eligibility Determination event, not in Sheet1 or R100.

    • none: everyone else.

    • Step 3: Assign groups and assert the shape

    Use the spec's groups 1–4. Groups 3 and 4 apply to Newark only, unless a Camden export arrived. A student in 2 groups gets one row listing both. Assert:

    • one row per region and student_number;
    • every row is in at least 1 group;
    • no row has enroll_status other than 0.

    Print counts by region and group. As a sanity check against 2026-11-10, Newark should be near 110 in group 3, Paterson at 11 in group 2, and every group 1 cell under 10.

    • Step 4: Build the Summary rows

    Add counts by region and group. Add counts of exited students whose past-year flag changes. Prod does not have the new values yet, so compute them with an ad hoc join:

    • Start from prod kipptaf_students.int_students__student_enrollments, with enroll_status != 0 and the region not Miami.
    • Left join kipptaf_powerschool.stg_powerschool__s_nj_ren_x on reenrollments_dcid.
    • Left join kipptaf_powerschool.stg_powerschool__s_nj_stu_x on students_dcid.
    • Both joins also match on _dbt_source_project.

    • New value: coalesce(njr.pid_504_tf, njs.pid_504_tf = 1, false). Count the rows where it differs from is_504.

    • Step 5: Write the Google Sheet

    Invoke anthropic-skills:google-workspace before the first Drive or Sheets write. Create the spreadsheet with tabs Newark, Camden, Paterson, and Summary. Columns per the spec: school, grade, student number, name, PID_504_TF, C_504_STATUS, EdPlan status, EdPlan plan end date, group, suggested fix, and notes. Expected: each tab's row count read back with get_values equals the local count.

    • Step 6: Hand it off

    Give the user the sheet link and the Summary counts in the terminal. Do not share the sheet. Post nothing student-level anywhere else.
