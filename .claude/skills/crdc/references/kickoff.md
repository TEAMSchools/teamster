# Kickoff doc and owners

For starting a cycle. Run [rollover.md](rollover.md) first if OCR's changes for
this cycle have not been mapped yet; the kickoff doc quotes its results.

## Make the doc

1. Create the cycle subfolder in the CRDC folder (`CRDC SY25-26` for the cycle
   reporting SY2025-26).
2. Copy the last cycle's kickoff doc (`CRDC SY2023-2024`) into it and rename it
   for the new cycle.
3. Replace every date. Do not carry the old ones forward and adjust; recompute
   each from this cycle's calendars.
4. Hand the draft to the user for the owner names; write roles if names are not
   confirmed.

## Sections the doc must keep

- Purpose, and a line in capitals that all this data becomes public record.
- What the CRDC is: every two years, reporting the previous school year,
  mandatory for districts receiving federal funds.
- The reference periods, with this cycle's dates per region:
  - Fall snapshot: the date from the model's rule (see
    [rollover.md](rollover.md) → Fall snapshot), after checking OCR's
    definition. SY2023-24 used 2 October 2023 because 1 October was a Sunday.
  - School year: first to last day of school, per region. Read them from the
    school calendars; regions end on different days.
  - School year + summer: first day of school to the day before next year
    starts.
- "All schools in Camden are reported as one school; same for Newark; same for
  Paterson."
- The owner table (below).
- Milestones (below).
- Data review items: law enforcement referrals, arrests, physical restraint, and
  harassment or bullying. These get a second look before entry because they are
  the numbers most likely to draw public attention.

## Owner table

Owners by domain for SY2025-26, by role. Confirm each with the user; the table
shifts between cycles.

| Domain                                          | Owner role                            |
| ----------------------------------------------- | ------------------------------------- |
| Academic data: enrollment, courses, SAT/ACT, AP | Data team lead                        |
| Distance education, dual enrollment, athletics  | Teaching and Learning director        |
| Special education, English learners             | Special education managing director   |
| Staffing, security staff                        | Data team senior analyst for talent   |
| Internet access and devices                     | Technology managing director          |
| Paterson                                        | Operations managing director (likely) |
| Civil rights compliance                         | Open: ask the data team lead          |
| Student discipline, arrests, harassment         | Open: ask the data team lead          |

Keep an "Open questions" block in the doc until each is settled:

- Who leads compliance (civil rights coordinator, harassment policy, sign-off)?
- Who owns student discipline?
- How do we get access to the Paterson instance of the CRDC submission system?
  Paterson is its own district in OCR's system and needs its own login. Ask
  before the entry window opens; access requests take time.
- How do we report students recorded as nonbinary, now that OCR removed the
  category?

## Milestones

Set these relative to OCR's official deadline, once OCR announces it. SY2023-24
used an internal deadline about three weeks before the official one (14 February
and 7 March 2025).

| Milestone         | What it means                                                               |
| ----------------- | --------------------------------------------------------------------------- |
| Kickoff           | Doc and collection sheet shared; each owner knows their tabs                |
| Gap deadline      | Owners flag anything they cannot answer, so the data team can find a source |
| Panic deadline    | A tab still empty is escalated to the owner's manager                       |
| Data entry starts | The data team begins typing into the OCR site                               |
| Internal deadline | Everything entered and every quality flag answered                          |
| Official deadline | Each district certified in OCR's system                                     |

Send the milestone dates to owners with their tabs named, so no one has to read
the whole doc to find their part.
