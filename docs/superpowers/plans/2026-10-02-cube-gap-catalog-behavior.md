### Notes

- **No behavior Cube exists** (confirmed: `src/cube/model/cubes/` has no
  `behavior`/`incident`/`suspension`/`referral` file), so every measure on this
  dashboard is `cube-covered: 0`. The best a future Cube behavior view could do
  today is build on `fct_behavioral_incidents` / `fct_behavioral_consequences` /
  `fct_family_communications`, joined to `dim_students` and `dim_locations` —
  exactly the blockers Asana names, except the actual shipped model names are
  `fct_behavioral_incidents`/`fct_behavioral_consequences` (not
  `fct_incidents`/`fct_behaviors`).
- **PBIS point-log data (`rpt_tableau__okrts_behavior`) has no mart at all.**
  It's a wholly separate DeansList log (`stg_deanslist__behavior`) from the
  incident/referral/suspension log (`int_deanslist__incidents__penalties`) that
  backs the marts. A behavior Cube covering only `fct_behavioral_incidents`/
  `_consequences` would miss every "Behavior Count"/"Total Points"/"Incentive"
  measure on the Entry Analysis, School Overview, and Landing Page dashboards.
- **Restraint fields are a genuine, confirmed mart gap** — not a guess.
  `int_deanslist__incidents__penalties` carries `restraint_used`,
  `restraint_duration`, `restraint_type`, but `fct_behavioral_consequences`'s
  properties yml does not list any of them. All 3 CRDC restraint measures and 2
  restraint dimensions are blocked on this until the mart is extended.
  "`fct_incidents`, `fct_behaviors`" named in Asana don't exist under those
  names; the closer mapping is `fct_behavioral_incidents` /
  `fct_behavioral_consequences` — but restraint columns are the one piece even
  those don't carry.
- **Open Asana measure tasks matched to live workbook metrics**:
  `behavior.suspension_rate_ytd` ↔ "Suspension Type – Rollup" / "Suspension Type
  (YoY running)"; `behavior.pct_receiving_incentive` ↔ "Progress to Quarterly
  Incentive" / "Quarterly Incentive Earned". Both are currently mart-missing,
  not merely un-cubed — the underlying rate logic lives only in the two
  `rpt_tableau__*` SQL files.
- **CSGF - Grid** (a zone on the Landing Page) produced no shelf fields in the
  parse — it appears to be a static grid/image zone, not a data visualization;
  excluded from both tables rather than guessed at.
- **Home Instruction dashboard carries almost no aggregated measures** — it's a
  compliance roster/queue (dates, approval flags, instructor info), which is why
  the Measures table has no Home Instruction rows; its content is captured in
  the Dimensions table instead.
- Judgment call: CRDC's suspended-Y1 flags (one/2-plus × OSS/ISS, 6 raw
  variants) were collapsed into a single mart-ready row since all 6 share the
  same two source columns (`is_suspension`, `suspension_type`) and differ only
  in the aggregation threshold (`=1` vs `>1`), which is simple `SUM`/`CASE`
  logic a mart or Cube measure could parameterize.
