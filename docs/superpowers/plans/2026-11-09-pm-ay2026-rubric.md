> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or

**Goal:** AY2026 coach scores flow through PM outlier detection and the teacher
development dashboard the way Grow scores them.

**Architecture:** The script's dbt input gains 7 core-value columns and a
`measure_set` column. The fit logic moves into a pure library helper that fits
each measure set separately. Teacher development selects ETR measures by name
prefix and adds a Values average that fills the 20% slot.

**Tech Stack:** dbt on BigQuery, Dagster, pandas, scikit-learn, pytest.

**Spec:** `docs/superpowers/specs/2026-11-09-pm-ay2026-rubric-design.md`

**Interfaces:**

- Produces:
  - `ETR_COLUMNS: list[str]`: `etr1a` … `etr5c` (19).
  - `MEASURE_SET_COLUMNS: dict[str, list[str]]`: `"etr_so"` → ETR + `so1`–`so8`;
    `"etr_values"` → ETR + the 7 core-value columns.
  - `MIN_FIT_ROWS = 3`.

    partition's rows of the set), merges with `_current` / `_global` suffixes on
    (`observer_employee_number`, `academic_year`, `form_term`), and returns
    records with `None` in place of every `NaN`.

  components).
