## 1. Report facts

### What it produces

- "This report is used to generate the New Jersey State Assessment Registration
  file to send to NJ SMART." (PS-SAR, Introduction)
- Output layout: 90 rows in the Report Output table, which is 86 data elements,
  3 filler fields (Filler Field 2, FillerField3, FillerField4) and End of
  Record. PS-SAR gives no begin/end positions and no item numbers (the Pre-ID
  for ACCESS page does, PS-PREID). Positions in section 2 are row order in
  PS-SAR.
- Record grain (one row per student, or per student per test) is not stated.
  Test Code, Session Name, Test Administrator and Extended Time each list both
  ELA and Math source fields (PS-SAR, Report Output). The Homeless Primary
  Nighttime Residence note mentions "students with Science Test Codes" (PS-SAR,
  Report Output row "Homeless Primary Nighttime Residence").

### Which students it selects (PS-SAR, Selection Criteria, Student Selection)

1. The student is actively enrolled in a valid ELA or math class on the Report
   Snapshot Date, OR the student has a test code override populated in Student
   Selection > State/Province - NJ > NJSLA.
2. The student is included in State Reporting and is included in NJ SMART
   extracts.
3. The student does not have an Exit Date before an Entry Date.

What makes an ELA or math class "valid" is not defined on any captured page.

### Grade-to-test mapping

- PS-SAR states none. Grade Level is "The student's grade level at the date of
  the assessment" (Report Output row "Grade Level"). Valid test codes are
  deferred to an appendix: "See the Appendix (/pssis-nj/latest/test-codes) for a
  list of valid test codes" (Report Output row "Test Code").
- The Test Codes appendix is indexed (PS-IDX row 365; PS-TREE: Appendix > Test
  Codes) but was not downloaded, so no grade-to-test rule from PowerSchool is in
  this catalog. The only grade-to-test mapping found is the in-house one in
  RPT-GS (section 5).
