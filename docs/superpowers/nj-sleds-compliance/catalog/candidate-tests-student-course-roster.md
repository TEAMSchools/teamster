# Candidate dbt tests: NJ SLEDS Student Course Roster

Draft for the data team planning session. Compiled 2026-10-20. Everything
labeled **proposal** is a suggestion for discussion, not a decision. Every
number is an aggregate. No student-level values appear here.

Inputs: `student-course-roster-fields.md` (rules, cited `HB`/`FAQ`/`PS-X`/`SYS`
as there), `existing-tests-inventory.md`, `pr4281-runbook-checks.md` (`RB n` =
runbook check n), `powerschool-ingestion-gaps.md`, the grade/credit backfill
spec and submission README (`SPEC`, `SUB`; `gate n` = SPEC validation-gate check
n), issue #5558 ("What backs up a ticketed test"), and the model YAML named in
each host. Facts marked `F#` were measured for this catalog (section 0).

How to read a row against #5558:

- **Ticket candidate** = test form `warn` + source-fixable `Y`. It needs a
  runbook before it opens tickets, plus a defending model and an error-level
  regression test (section C).
- **C only** = the source value is correct or unfixable, so under "No waivers"
  the data team fixes it in SQL and only an error-level test on the defending
  model exists.

### Shared predicates and patterns

- `<yr>`: `<year column> >= <cutoff>`. The cutoff is open (E2).
- `<nj>` (kipptaf hosts only):
  `_dbt_source_project in ('kippnewark', 'kippcamden')`, plus `'kipppaterson'`
  if E1 says so.
- `<live>`: `not is_dropped_section` (`bce`, `ice`) or `sectionid > 0` (`cc`).
- `<rep>`:
  `coalesce(exclude_course_submission_tf, 0) = 0 and coalesce(sections_exclude_state_rpt_yn, 0) = 0`,
  plus school `state_excludefromreporting = 0`. The section-level NJ exclude
  flag is not visible (D-1).
- `<sec>` / `<prior>`: SCED level from the SCED lookup (B-1). Interim:
  `safe_cast(nces_subject_area as int64) between 1 and 25` /
  `between 51 and 75`. Sources disagree on the Secondary range (PS-X 01-22,
  PS-DIST 01-24, SCED file 01-25).
- `<graded>`:
  `(<sec> and courses_credit_hours > 0) or (<prior> and left(course_span, 2) in ('06', '07', '08', '09', '10', '11', '12'))`.
  Tests the span start, per SPEC (E7). Membership, not `>= '06'`, because `KG`
  sorts above `06`.
- `<ended>`: `exit_date <= current_date('America/New_York')`.
- `SPAN_RE` = `r'^(PK|KG|0[1-9]|1[0-2]){2}$'`; `SEQ_RE` = `r'^[1-9][1-9]$'`.
- `ALPHA18` = `A A+ A- B B+ B- C C+ C- D D+ D- E E+ E- F F+ F-`; `COMP5` =
  `P F W I NG`.

### Fix owners and confidence

- **school scheduler**: sections, enrollments, teacher assignments.
- **school ops**: student demographics, posting and storing grades.
- **Compliance**: course-catalog state coding (`S_NJ_CRS_X`), dual enrollment,
  exclude-from-roster decisions. Proposed; the catalog owner is unconfirmed
  (E4).
- **data team**: PowerSchool district/school setup (CDS, terms, grade scales)
  and the SQL behind `D1`.
- **H** = the state lists it as an error, and the host carries the data today or
  after P1. **M** = stated rule, but the host is a proxy or has a known gap.
  **L** = inference or guidance only.
